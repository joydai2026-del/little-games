# Avery Games: subscription launch plan (drafted 2026-09-29)

**Locked already:** Paid = $39/year; the starter level = 1 saved list + 1 play mode (little-games AGENTS.md). This plan keeps both and only adds proposals.
**Decision inputs:** JD's idea is about $39/yr per teacher. The earlier outline (2026-09-24) had $9/mo or $89/yr. The teacher reviewer's gut feel is $3–5/mo or $30–40/yr per teacher and $150–300/yr per campus with invoice/PO, and she thinks a starter tier plus a paid seasonal library beats a hard paywall.
**House rule:** site copy never calls the games "free". Use "Starter", "trial", or "free trial".

## 1. Tiers (recommendation)

| Tier | Price | What's in it | Why |
|---|---|---|---|
| **Starter** (no card) | $0, always called "Starter" on the site | **Locked shape (little-games AGENTS.md): 1 saved list (one vocab deck) + 1 play mode on that list**, class code join, no student logins | Keeps today's "paste your list, kids play" hook and seeds word of mouth inside DLI programs. The site must say "Starter", never "free games" |
| **Teacher** | **$39/yr (locked)**. Proposals for JD: optional $4.99/mo, and a **founding-teacher $29/yr, locked while subscribed** (first 100 waitlist members) | Everything, plus: level-sorted word sets aligned to Utah DLI levels and Better Immersion themes; unlimited saved lists; the 30-second custom list; **projector/whole-class mode**; simplified/traditional and pinyin on/off toggles; **a new seasonal game each month tied to that month's TPT pack**; printable 田字格 sheets from any list | Matches JD's $39 and the reviewer's $30–40; the monthly seasonal drop is the retention hook |
| **Campus** | **$199/yr up to 10 teachers**, +$15 per extra teacher; invoice/PO | Teacher for everyone, plus an **admin usage view** (plays per class, words practiced), a shared school word bank, and priority requests | Within the reviewer's $150–300 range; POs unlock school budgets that teachers can't spend personally |

Trials: 14-day Teacher trial, no card, at signup. Campus: a 30-day pilot for one grade team.

Billing: Gumroad is already set up for Avery (averystudio.gumroad.com) and supports memberships, so v1 needs no new payment stack. Stripe comes later for campus invoices. The campus PO flow is manual in v1 (a PDF invoice from the business email).

## 2. Feature build order (from the teacher review, ranked by conversion impact)
1. Projector / whole-class mode (the teacher runs one screen; no devices needed). Removes the "my K-1 kids don't have tablets" objection.
2. No-login student mode stays as it is (class code + first name). Protect it: it's the privacy selling point.
3. Simplified/traditional + pinyin toggles.
4. Level-sorted word sets: start with Halloween, fall, family, school, and numbers. Map them to Utah DLI grade levels and Better Immersion themes (Self / Relationships / Community / World for K; Self / Responsibilities / Changes / Actions for 1–5). Name themes generically. Don't use third-party trademarks as product names without permission.
5. The 30-second custom list (paste, then auto pinyin/gloss, then play), which mostly exists already.
6. Monthly seasonal game tied to the TPT pack: Oct Halloween, Nov Thanksgiving/fall, Dec winter/冬至, Jan–Feb Chinese New Year (Feb 6 2027), Apr Qingming/spring, May–Jun Dragon Boat.
7. Admin usage view (Campus).
8. Accounts plus the paywall gate: teacher-only login (magic link), and never student accounts.

## 3. Funnel wiring
- **TPT → games:** every Halloween/strokes listing already carries the averystudio.org/games line. Add to each PDF's last page: "Play these words as a class game: averystudio.org/games" with a QR. Add a FREE TPT "Avery Games word-list starter" printable (word lists per season plus a QR to /games and the waitlist).
- **Games → TPT:** after each game round, show a "Print this week's practice" card linking the matching TPT pack. On /games, add a "Pair with" printable under each game card (Trace Race → FREE strokes / Bridge; Whack-a-Word → the current seasonal Mini Bundle).
- **Guides → waitlist:** done (PR #91). Every guide ends in the founding-teacher waitlist.
- **Waitlist → founding offer:** at launch, email the list the $29/yr founding link (Gumroad), open for 14 days.
- **Demo videos:** 15–30 second vertical captures of Trace Race, Stroke Reveal, and Whack-a-Word (the gifs already exist in `assets/avery/games/`). Use them on the /games cards, Pinterest video pins, Reels/Shorts, and 小红书.
